# Ideas inbox (example)

This file only shows the format. Copy it to `brand/ideas.md`, delete these
examples and add real things. `brand/ideas.md` stays on this Mac and is never
committed, because it can hold client details.

Claude writes Client win, Announcement and Hiring posts only from entries in
`brand/ideas.md`, and uses only the facts written there. Start each heading with
the post type, and always say whether a client can be named.

## Client win: EXAMPLE invoice processing for a logistics company

- Problem: three people spent two days a week typing invoice data into the ERP.
- What we built: a document AI that reads invoices and fills in the ERP, with a
  person checking anything it isn't sure about.
- Result: data entry went from two days to two hours a week.
- Can we name the client? No.

## Hiring: EXAMPLE AI engineer

- Full-time, remote or hybrid.
- How to apply: message the Forethrive page.

## Announcement: EXAMPLE new office

- What happened and when, in a line or two.

## Topic: EXAMPLE something we want covered

- A few words on the idea. Claude turns it into an AI insight post.
